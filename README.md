## Sobre o Projeto

Implementação de três módulos aplicando o ciclo **Red, Green e Refactor** do Desenvolvimento Orientado a Testes (TDD):
1. **Calculadora de operações:** soma, subtração, multiplicação e divisão com tratamento de divisão por zero.
2. **Sistema de descontos:** aplicação progressiva de descontos (0%, 10% e 20%) com arredondamento para duas casas decimais.
3. **Cálculo de frete:** definição do valor de frete por faixa de valor da compra.

## Pré-requisitos

- Node.js (v18 ou superior)
- npm
